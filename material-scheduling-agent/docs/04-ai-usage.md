# 04 AI 使用记录

## 使用范围

本项目使用 Codex 辅助完成需求拆解、工具与存储实现、模型接口、执行循环、测试、示例生成及文档。AI 还通过并行子任务协助检查验收边界。代码与文档的大部分初稿由 AI 生成。

未把离线规则 Mock 称为真实模型，也未凭空生成真实模型 Trace。没有提供或提交真实 API 密钥与隐私素材。

## 可核实的人工作用

当前对话中，用户提供考核题目并明确选择第 1 题。除此之外，候选人本人在实现、调试、代码修改和验证方面的贡献暂无可核实记录，本文件不代为编造。

提交前请候选人依据实际工作补充：

| 待本人填写项 | 需要记录的事实 |
| --- | --- |
| 个人实现与修改 | 文件、修改原因、修改前后行为 |
| 独立理解与核验 | 能解释的边界、复现命令、实际观察 |
| 模型接入验证 | 模型及版本、调用日期、实际 Trace 路径 |
| 实际用时 | 本人投入时长与未完成项 |

## 验证责任

AI 生成内容不作为正确性的证明。可执行测试和真实运行输出用于核对工程行为；真实模型的决策能力需要单独的模型运行记录。本次实际运行 35 项测试全部通过，并记录 11 条离线 CLI 执行；测试、示例及其引用以 [评估文档](03-evaluation.md) 为准。真实模型未调用，这些结果不证明模型决策效果。

考核要求如实记录使用范围、个人贡献和验证结果。提交时应保留这份边界说明，并补充实际发生的工作，不能把 AI 的实现经历改写为个人经历。
