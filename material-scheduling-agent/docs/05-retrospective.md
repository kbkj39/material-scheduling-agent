# 05 复盘与下一步

## 工程复盘

本实现要解决的主要难点是：在模型可自由选择动作的前提下，让审核、用户确认、排期冲突和保存事实保持一致。仅在提示词中写“不要越权”不足以保证边界，因此保存工具执行前置条件检查与事务复验，最终输出根据工具回执生成。

另一处难点是幂等。稳定请求 ID 不能只防止重复插入，还要识别同一键改变参数的情况；否则调用方可能误以为新要求已经保存。当前用唯一约束与业务参数指纹分别处理两类情况。

以上是对实现选择的工程说明，不是候选人的个人学习经历。候选人尚未提交个人复盘，需在实际运行和修改后补充最难问题、学到的内容及具体改进。
